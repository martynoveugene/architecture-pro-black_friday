# <a name="_qmphm5d6rvi3"></a>**Решение**

## <a name="_3bfxc9a45514"></a>**Для коллекции products**

| **Операция чтения**                                       | **primary или secondary** | **Допустимая задержка** | **Обоснование выбора**                                                                                                             |
|:----------------------------------------------------------|:--------------------------|:------------------------|:-----------------------------------------------------------------------------------------------------------------------------------|
| Поиск товаров по категориям и фильтрация по диапазону цен | secondary                 | Маленькая(<100мс)       | Данные не часто меняются, но цена очень важный параметр, который должен быть актуальным, поэтому секондари с минимальной задержкой |
| Описание товара на странице продукта                      | secondary                 | Большая (>10c)          | Все кроме цены в описании товара допускает отображение с большой задержкой                                                         |
|                                                           |                           |                         |                                                                                                                                    |

Дополнительная коллекция quantity

| **Операция чтения**                         | **primary или secondary** | **Допустимая задержка** | **Обоснование выбора**                                                                                 |
|:--------------------------------------------|:--------------------------|:------------------------|:-------------------------------------------------------------------------------------------------------|
| Чтение для обновления остатков при покупках | primary                   | Совсем без задержки     | Критически важно работать с актуальным значением и всегда читать и изменять именно актуальное значение |
|                                             |                           |                         |                                                                                                        |

## <a name="_3bfxc9a45514"></a>**Для коллекции orders**

| **Операция чтения**                            | **primary или secondary** | **Допустимая задержка** | **Обоснование выбора**                                                                   |
|:-----------------------------------------------|:--------------------------|:------------------------|:-----------------------------------------------------------------------------------------|
| Поиск истории заказов конкретного пользователя | secondary                 | Средняя (1-5 сек)       | Не критично если история чуть задержится, пользователь всегда может запросить ее еще раз |
| Отображение статуса заказа                     | secondary                 | Маленькая(<100мс)       | Актуальный Статус важнее  чем история, но можно запросить еще раз                        |
|                                                |                           |                         |                                                                                          |


## <a name="_qmphm5d6rvi3"></a>**Для коллекции carts**

| **Операция чтения**       | **primary или secondary** | **Допустимая задержка** | **Обоснование выбора**                                             |
|:--------------------------|:--------------------------|:------------------------|:-------------------------------------------------------------------|
| Чтение при операции с ней | primary                   | Совсем без задержки     | Важно знать точное количество в корзине при изменениях по позициям |
|                           |                           |                         |                                                                    |


### <a name="_bjrr7veeh80c"></a>**Альтернативы**

1. Можно работать только с актуальными данными всегда и не переносить операции чтения на secondary узлы,
но это уменьшит общую производительность системы.

### **Недостатки, ограничения, риски**

1. Сложность настройки патерна Command Query Responsibility Segregation
2. Сложность настройки этого патерна отдельно для каждой сущности.
